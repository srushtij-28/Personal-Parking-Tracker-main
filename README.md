# Personal Parking Tracker

A simple Python command-line application to manage vehicle parking
entries, exits, parking slots, and parking charges.

## Features

- Register vehicle entry
- Automatically assign available parking slots
- View currently parked vehicles
- Search vehicles by registration number
- Record vehicle exit
- Calculate parking charges
- View parking history
- Check available parking slots
- Display parking statistics
- Store records in JSON format

## Technologies Used

- Python
- JSON
- File Handling
- Date and Time Handling
